# Documentation

[kgmem](../README.md)

- [Tutorial](tutorials/first-run.md): run the demo, edit facts and read a saved scratchpad.
- [How-to guides](how-to/index.md): installation, Python use, training and evaluation.
- [Reference](reference/index.md): APIs, configuration and checkpoint compatibility.
- [Explanation](explanation/index.md): how linking, traversal and writable memory work.
- [Experiments](experiments/index.md): results, methods and limitations.

Start with the tutorial to run the included SmolLM2 adapter. The experiment reports distinguish
frozen-backbone results from LoRA and optional custom-backbone runs.

Pages follow [Diátaxis](https://diataxis.fr/): tutorials teach through an example, how-to guides
complete a task, reference documents interfaces, and explanation develops the design.
Commands run from the checkout root after an editable install unless stated otherwise.
Datasets belong under `data/`; generated checkpoints, caches and predictions belong under `runs/`.
